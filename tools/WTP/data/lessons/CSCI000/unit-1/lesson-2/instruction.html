Tutorial

Almost every program needs to remember things: a user's name, a score in a game, the price of an item in a basket. Programs store this information in variables.


What Is a Variable?

A useful way to picture a variable is as a labelled box. The label is the variable's name, and the thing inside the box is its value. Whenever you use the name in your code, Python looks inside the box and uses whatever is stored there.

You create a variable by writing a name, an equals sign, and a value:

name = "Sam"
age = 21
print(name)
print(age)

This will output:

Sam
21

Let's look at what happens line by line:

  1. name = "Sam" creates a box labelled name and puts the string "Sam" inside it.
  2. age = 21 creates a second box labelled age holding the number 21.
  3. print(name) looks inside the name box and prints what it finds.
  4. print(age) does the same for age.

Notice that print(name) has no quotes. With quotes, print("name") would print the word name itself rather than the value stored in the variable.


The Equals Sign Means "Store"

In maths, = means two things are equal. In Python, it means "take the value on the right and store it in the variable on the left". This is called assignment. Python always works out the right-hand side first, then stores the result.

Because of this, a variable can be given a new value at any time. The old value is simply thrown away:

score = 10
score = 15
print(score)
15

This is why they are called variables: their values can vary as your program runs.


Naming Rules

Python has a few rules about what you can call a variable, plus some conventions that make code easier to read:

  • Names can contain letters, numbers and underscores, but cannot start with a number. player1 is fine; 1player is not.
  • Names cannot contain spaces. Use an underscore instead.
  • Names are case-sensitive: Age and age are two different variables.
  • By convention, Python uses lowercase words separated by underscores, such as first_name. This style is called snake_case.
  • Choose names that describe the value. total_price tells the reader exactly what it holds; x tells them nothing.

Data Types

Every value in Python has a type, which tells Python what kind of data it is and therefore what you can do with it. You can add two numbers together, but it makes no sense to multiply someone's name by their postcode. The four basic types are:

  • int (integer): a whole number, such as 42 or -7
  • float (floating-point number): a number with a decimal point, such as 1.75
  • str (string): text, such as "Leeds"
  • bool (boolean): either True or False, used for yes/no values

You do not have to tell Python which type a variable is; it works it out from the value you give it. You can always check using the type() function:

print(type(42))
print(type(1.75))
print(type("Leeds"))
print(type(True))
<class 'int'>
<class 'float'>
<class 'str'>
<class 'bool'>

Why Types Matter

The same symbol can behave differently depending on the types involved. Compare these two lines:

print(2 + 2)
print("2" + "2")
4
22

The first adds two numbers. The second joins two strings together, because "2" in quotes is text, not a number. Mixing up types is one of the most common causes of bugs for new programmers, so it is worth getting into the habit of asking "what type is this?"


Common Mistakes

  • Using a variable before creating it, or misspelling its name, causes a NameError.
  • Putting quotes around a variable name prints the name itself instead of its value.
  • Writing true or false in lowercase. Booleans must start with a capital letter: True and False.

Recap

  • A variable is a named place to store a value.
  • = stores the value on the right in the variable on the left.
  • The four basic types are int, float, str and bool.
  • The type of a value decides what you can do with it.
