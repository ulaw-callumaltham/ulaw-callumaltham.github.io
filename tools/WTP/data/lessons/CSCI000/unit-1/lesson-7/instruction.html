Tutorial

Until now, every line of every program has run, one after another, every time. Real programs need to make choices: show an error if the password is wrong, give a discount if the customer is a student, end the game if the player runs out of lives. In this lesson you will use the booleans from Lesson 6 to control which parts of your code run.


The if Statement

An if statement runs a block of code only when a condition is True:

temperature = 25

if temperature > 20:
    print("It's warm today.")
    print("Don't forget your sunglasses.")

print("Have a good day!")
It's warm today.
Don't forget your sunglasses.
Have a good day!

Here is how Python reads it:

  1. It checks the condition temperature > 20. Since 25 is greater than 20, the condition is True.
  2. Because the condition is True, it runs the two indented lines.
  3. The final print is not indented, so it is not part of the if. It runs no matter what.

Try changing temperature to 15. The two indented lines are skipped, and only Have a good day! is printed.


Colons and Indentation

Two details are essential:

  • The line containing the condition ends with a colon :. The colon means "the block of code that belongs to this starts on the next line".
  • The code that belongs to the if is indented, normally by four spaces. Many languages use curly brackets to group code; Python uses indentation instead. Every line indented at the same level after the colon is part of the block, and the block ends at the first line that is not indented.

Because indentation has meaning in Python, it must be consistent. Mixing different amounts of indentation causes an IndentationError.


else: The Alternative

Often you want to do one thing if a condition is true and something else if it is not. else provides that alternative, and needs no condition of its own:

age = 15

if age >= 18:
    print("You can vote.")
else:
    print("You can't vote yet.")
You can't vote yet.

Exactly one of the two blocks will always run; never both, never neither.


elif: More Than Two Options

When there are several possibilities, use elif (short for "else if") to check further conditions in turn:

temperature = 12

if temperature > 20:
    print("Warm")
elif temperature > 10:
    print("Mild")
else:
    print("Cold")
Mild

Python checks each condition from top to bottom. As soon as it finds one that is True, it runs that block and skips the rest of the chain entirely. The else at the end catches anything that did not match.


Why the Order Matters

Because only the first matching block runs, the order of your conditions is important. Look at this incorrect version:

temperature = 25

if temperature > 10:
    print("Mild")
elif temperature > 20:
    print("Warm")
Mild

25 is greater than 10, so the first condition is True and Python prints Mild. It never reaches the check for warm weather. When conditions overlap like this, put the most specific (here, the highest) one first.


Common Mistakes

  • A missing colon at the end of an if, elif or else line causes a SyntaxError.
  • Forgetting to indent, or indenting inconsistently, causes an IndentationError.
  • Using = instead of == in a condition.
  • Putting conditions in the wrong order, so a later one is never reached.

Your Task

Write a program that converts a mark into a UK degree classification:

  • 70 or above: First
  • 60 to 69: Upper Second (2:1)
  • 50 to 59: Lower Second (2:2)
  • 40 to 49: Third
  • Below 40: Fail
  1. Ask the user to enter a mark and convert it to an integer.
  2. Use if, elif and else to print the correct classification.
  3. Test it with the boundary marks 70, 69, 40 and 39. Testing the values either side of a boundary is a good habit, because that is where mistakes usually hide.

Extension Tasks

  • Before classifying, check the mark is between 0 and 100. If not, print Invalid mark instead.
  • Write a cinema ticket pricer: under 12 pays £5, 65 or over pays £6, everyone else pays £10. Then ask whether they are a student, and if so take £2 off. You can put an if inside another if; just indent it one more level.

Recap

  • if runs a block only when its condition is True.
  • elif checks further conditions, and else catches everything else.
  • Only the first matching block runs, so order matters.
  • Conditions end with a colon, and the block is indented.
