Tutorial

Text is everywhere in software: names, messages, emails, web pages, passwords. Being able to build, inspect and change strings is one of the most practical skills in programming, and Python makes it particularly easy.


Joining Strings

You can join (or concatenate) strings with the + operator. When used with strings, + does not add; it sticks the strings together end to end:

first_name = "Ada"
last_name = "Lovelace"
full_name = first_name + " " + last_name
print(full_name)
Ada Lovelace

Notice the " " in the middle. Python never adds spaces for you, so without it you would get AdaLovelace.


Mixing Strings and Numbers

Python will not let you join a string and a number directly:

age = 36
print("Age: " + age)
TypeError: can only concatenate str (not "int") to str

Python refuses because it cannot tell what you mean. Do you want to add numbers or join text? Rather than guessing, it raises a TypeError. One fix is to convert the number to a string first with str(age), which turns 36 into "36".


f-strings

Joining lots of pieces with + quickly becomes messy. A cleaner approach is an f-string (formatted string). Put the letter f before the opening quote, then place any variable inside curly brackets { }. Python swaps each one for its value and handles the conversion to text for you:

print(f"{full_name} was {age} when she died.")
Ada Lovelace was 36 when she died.

f-strings are the most common way to build messages in modern Python, and you will use them throughout the rest of this unit.


String Methods

Strings come with built-in tools called methods. You use a method by writing a dot after the string, followed by the method's name and brackets. You can think of it as asking the string to do something to itself:

print(len(full_name))         # number of characters
print(full_name.upper())      # all capitals
print(full_name.lower())      # all lowercase
print(full_name.replace("Ada", "Augusta"))
12
ADA LOVELACE
ada lovelace
Augusta Lovelace

len() is a function rather than a method, which is why it is written differently, but it is used constantly with strings. It counts every character, including spaces.

An important detail: string methods do not change the original string. full_name.upper() gives you back a new string in capitals, and full_name itself stays the same. If you want to keep the result, store it in a variable, e.g. shouting = full_name.upper().


Indexing and Slicing

A string is a sequence of characters, and each character has a numbered position called an index. Python starts counting at 0, so the first character is at index 0, the second at index 1, and so on. Negative indexes count backwards from the end, so -1 is always the last character.

print(full_name[0])     # first character
print(full_name[-1])    # last character
print(full_name[0:3])   # characters 0, 1 and 2
A
e
Ada

The third line is a slice, which takes a section of the string. [0:3] means "start at index 0 and stop before index 3". The stop position is never included. This can feel odd at first, but it means [0:3] always gives you exactly 3 characters.


Common Mistakes

  • Forgetting the f before an f-string, so the curly brackets are printed literally.
  • Forgetting spaces when joining strings with +.
  • Expecting a method to change the original string without storing the result.
  • Starting to count from 1. The first character is at index 0.

Recap

  • + joins strings; Python never adds spaces for you.
  • f-strings let you put variables inside text using { }.
  • Methods such as .upper() return a new string and leave the original unchanged.
  • Indexes start at 0, and slices stop before the end position.
