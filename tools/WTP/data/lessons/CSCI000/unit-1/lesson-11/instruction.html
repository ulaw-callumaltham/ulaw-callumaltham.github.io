Tutorial

A function is a named block of code that performs a task. You have already used built-in functions such as print(), len() and input(). Now you will write your own.

def greet():
    print("Hello!")
    print("Welcome to Python.")

greet()
greet()

The def keyword defines the function. The indented code inside it only runs when the function is called by writing its name followed by brackets.


Parameters

Parameters let you pass information into a function:

def greet(name):
    print(f"Hello, {name}!")

greet("Sam")
greet("Priya")
Hello, Sam!
Hello, Priya!

Returning a Value

The return keyword sends a result back to wherever the function was called, so you can store it or use it in other calculations:

def add(a, b):
    return a + b

total = add(3, 4)
print(total * 2)
14

The difference between print and return is important: print only displays a value, whereas return hands it back so your program can keep using it. A function without a return gives back None.
