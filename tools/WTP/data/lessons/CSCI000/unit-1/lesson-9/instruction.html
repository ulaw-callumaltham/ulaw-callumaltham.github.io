Tutorial

In the last lesson you used while loops, which repeat until a condition changes. Python's other loop, the for loop, is designed for a slightly different job: going through a sequence of items one at a time. In practice, for loops are the more common of the two.


Looping Over a Sequence

A for loop takes each item in a sequence in turn and runs the indented block once for each one. A string is a sequence of characters, so you can loop over it:

for letter in "Python":
    print(letter)
P
y
t
h
o
n

You can read the first line almost as English: "for each letter in the string Python, do the following". The variable letter is called the loop variable. On the first pass it holds "P", on the second "y", and so on, until there are no characters left and the loop ends.

You choose the name of the loop variable yourself. letter describes what it holds, which makes the code easy to read.

Unlike a while loop, there is no counter to set up and update, and no condition that might accidentally never become False. The for loop handles all of that for you, which is why it cannot become an infinite loop when working through a sequence.


The range() Function

Often you want to repeat something a set number of times, or work through a series of numbers. The range() function produces a sequence of numbers for a for loop to work through. It can be used in three ways:

  • range(5) gives 0, 1, 2, 3, 4. With one number, it starts at 0 and stops before that number.
  • range(1, 6) gives 1, 2, 3, 4, 5. With two numbers, you choose the start and the stop.
  • range(0, 11, 2) gives 0, 2, 4, 6, 8, 10. The third number is the step, i.e. how much to go up by each time. A negative step counts down.
for i in range(1, 4):
    print(f"Round {i}")

Round 2
Round 3

As with slicing in Lesson 4, the stop value is never included. This trips almost everyone up at first. A useful rule: range(1, 4) stops before 4, so if you want to include a number, set the stop to one more than it.

You will often see i used as the loop variable when counting. It is a long-standing convention, short for "index".


Building Up a Total

A very common pattern is to create a variable before the loop and add to it on each pass. This is called an accumulator:

total = 0

for number in range(1, 5):
    total += number

print(total)
10

Tracing it: total starts at 0, then becomes 1, then 3, then 6, then 10. The print is not indented, so it runs once after the loop has finished rather than on every pass.


while or for?

  • Use a for loop when you know how many repetitions you need, or when you are working through a sequence.
  • Use a while loop when you are repeating until something happens, such as the user typing the right answer.

Common Mistakes

  • Forgetting that the stop value is excluded. range(1, 10) stops at 9.
  • Indenting a line that should run once, such as a final total, so it runs on every pass.
  • Forgetting to convert input before passing it to range(), which needs a whole number.

Recap

  • A for loop runs once for each item in a sequence.
  • range(start, stop, step) produces a sequence of numbers, stopping before stop.
  • An accumulator is a variable you add to on each pass of a loop.
  • Use for when you know how many times; use while for "until".
