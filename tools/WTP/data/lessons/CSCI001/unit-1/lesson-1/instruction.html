Tutorial

In this unit you will build the first version of your own portfolio website. A portfolio site is a place on the web that you control, where employers can find out who you are, what you can do, and how to contact you. It sits at the centre of your web presence and links out to your LinkedIn and GitHub profiles.

You will cover HTML and CSS in much more depth in your Web Technologies module, so this unit focuses on just enough to get a working site. Each lesson adds one new section to the same page, and the final lesson brings everything together into a template you can keep building on throughout the year.


In this unit, we will cover:

  • The structure of an HTML page
  • Organising a page into meaningful sections
  • Adding text, images and links
  • Styling a page with CSS
  • Building common portfolio components: a skills list, project cards, a timeline and a contact section
  • Putting it all together into your own portfolio template

What Is HTML?

HTML (HyperText Markup Language) describes the content and structure of a web page: which parts are headings, which are paragraphs, which are images and links. It does not control how things look; that is the job of CSS, which you will meet in Lesson 4.

HTML works by wrapping content in tags. Most tags come in pairs: an opening tag such as <p> and a closing tag with a forward slash, such as </p>. Together with the content between them, they form an element.

<p>This is a paragraph.</p>

The browser does not display the tags themselves. It reads them to understand what each piece of content is, and displays it accordingly.


The Structure of a Page

Every HTML page follows the same basic outline. Open the starter code and you will see something like this:

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>My Portfolio</title>
</head>
<body>
    <!-- Visible content goes here -->
</body>
</html>

Working from the top:

  • <!DOCTYPE html> tells the browser this is a modern HTML page.
  • <html lang="en"> wraps the whole page. The lang attribute tells browsers and screen readers the page is in English.
  • <head> holds information about the page that is not shown on it. The <title> appears in the browser tab and in search results, so it matters for how people find you.
  • <body> holds everything visitors actually see.

The lines starting <!-- and ending --> are comments. Like Python comments, the browser ignores them. The starter code uses them to mark your TODO tasks.


Headings and Paragraphs

HTML has six levels of heading, from <h1> (most important) to <h6>. A page should have exactly one <h1>, which says what the whole page is about. On a portfolio, that is your name.

<h1>Alex Morgan</h1>
<p>MSc Computing student | Aspiring data analyst</p>
<p>I spent six years in retail management before moving into technology.</p>

Your Task

  1. Change the page <title> to your name followed by | Portfolio.
  2. Add an <h1> containing your name.
  3. Add a paragraph with a one-line tagline describing who you are and what you are aiming for.
  4. Add a second paragraph introducing yourself in one or two sentences.

Your tagline is the first thing an employer reads, so make it specific. "Student" tells them very little; "MSc Computing student with a background in finance" tells them a lot.


Extension Tasks

  • Right-click the preview and choose View Page Source or Inspect (if your browser allows it inside the preview) to see how the browser has read your HTML.
  • Try adding an <h2> and an <h3> to see how the sizes change by default. You will remove them in the next lesson.

Recap

  • HTML describes the content and structure of a page using tags.
  • <head> holds information about the page; <body> holds what visitors see.
  • Use one <h1> per page; on a portfolio, it is your name.
