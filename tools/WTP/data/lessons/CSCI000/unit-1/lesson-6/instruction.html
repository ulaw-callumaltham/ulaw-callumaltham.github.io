Tutorial

Programs constantly need to answer yes-or-no questions: is the password correct? Is the user old enough? Python answers these with the boolean values True and False.


Comparison Operators

  • == equal to
  • != not equal to
  • < less than
  • > greater than
  • <= less than or equal to
  • >= greater than or equal to
print(5 > 3)
print(10 == 9)
print("apple" == "Apple")
True
False
False

Notice that string comparisons are case-sensitive. Also be careful not to confuse = (assigns a value) with == (compares two values).


Logical Operators

You can combine conditions with and, or and not:

  • and is True only if both sides are True
  • or is True if at least one side is True
  • not flips True to False and vice versa
is_weekend = True
is_raining = False
print(is_weekend and not is_raining)
print(is_weekend or is_raining)
True
True
