Tutorial

Strings are one of the most common data types you will work with. Python gives you many ways to combine, format and inspect them.


Joining Strings

You can join (concatenate) strings with +:

first_name = "Ada"
last_name = "Lovelace"
full_name = first_name + " " + last_name
print(full_name)
Ada Lovelace

You cannot join a string and a number directly. This causes a TypeError:

age = 36
print("Age: " + age)

One fix is to convert the number to a string first with str(age).


f-strings

A neater approach is an f-string. Put an f before the opening quote and place variables inside curly brackets:

print(f"{full_name} was {age} when she died.")
Ada Lovelace was 36 when she died.

Useful String Tools

print(len(full_name))         # number of characters
print(full_name.upper())      # all capitals
print(full_name.lower())      # all lowercase
print(full_name.replace("Ada", "Augusta"))

Indexing and Slicing

Each character has a position called an index. Indexes start at 0, and negative indexes count from the end.

print(full_name[0])     # first character
print(full_name[-1])    # last character
print(full_name[0:3])   # characters 0, 1 and 2
A
e
Ada
