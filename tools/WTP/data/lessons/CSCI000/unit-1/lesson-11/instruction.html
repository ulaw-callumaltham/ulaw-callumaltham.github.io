Tutorial

You have been using functions since your very first line of Python: print(), input(), len() and int() are all functions that someone else wrote. In this lesson you will write your own.


Why Write Functions?

A function is a named block of code that performs one specific job. Writing your own functions has several big advantages:

  • Reuse: write the code once, then use it as many times as you like by calling its name.
  • Readability: a well-named function such as calculate_vat() tells the reader what the code does without them needing to read every line.
  • Easier fixes: if there is a bug, you fix it in one place rather than in every copy.
  • Breaking problems down: large programs are built from many small functions, each solving one part of the problem.

Defining and Calling a Function

def greet():
    print("Hello!")
    print("Welcome to Python.")

greet()
greet()
Hello!
Welcome to Python.
Hello!
Welcome to Python.

There are two separate steps here:

  1. Defining the function. The def keyword (short for "define") is followed by the function's name, round brackets and a colon. The indented lines underneath are the function's body. Defining a function does not run it; it just teaches Python what greet means.
  2. Calling the function. Writing greet() tells Python to run the body. Here we call it twice, so the messages appear twice.

A function must be defined before it is called, so definitions usually go at the top of your file. Function names follow the same snake_case rules as variables.


Parameters: Passing Information In

A function becomes far more useful when you can give it information to work with. You do this with parameters, which are variables listed inside the brackets of the definition:

def greet(name):
    print(f"Hello, {name}!")

greet("Sam")
greet("Priya")
Hello, Sam!
Hello, Priya!

When you call greet("Sam"), the value "Sam" (called an argument) is placed into the parameter name, and the body runs using it. The next call puts "Priya" in instead. Functions can have several parameters, separated by commas.


Returning a Value

So far our functions have printed things. But often you want a function to work something out and give the answer back to your program so you can keep using it. That is what return does:

def add(a, b):
    return a + b

total = add(3, 4)
print(total * 2)
14

When Python reaches return, it leaves the function immediately and sends the value back to wherever the function was called. Here, add(3, 4) is replaced by 7, which is stored in total and then doubled.


print Versus return

This is the most important idea in the lesson, and a very common source of confusion. Think of a calculator:

  • print is like the calculator showing the answer on its screen. You can see it, but you cannot do anything else with it in your program.
  • return is like the calculator handing you the answer on a piece of paper. You can store it, use it in another calculation, or print it yourself.

A function without a return statement gives back a special value called None, meaning "nothing". If you see None appearing in your output, it usually means you printed the result of a function that does not return anything.


Common Mistakes

  • Forgetting to call the function. Defining it alone does nothing.
  • Forgetting the brackets when calling it: greet instead of greet().
  • Using print when you meant return, so the result cannot be used elsewhere.
  • Calling a function before it is defined, which causes a NameError.

Recap

  • def defines a function; calling it by name runs it.
  • Parameters let you pass information into a function.
  • return sends a value back so your program can use it.
  • print only displays a value; a function without return gives back None.
