Tutorial

You have built every component of a portfolio site. The starter code for this lesson contains a complete template that brings them all together, so whether or not you finished every lesson, everyone starts this task from the same complete page. Your job now is to make it yours.

This is not the finished article. It is a starting point you will keep improving throughout the year as you complete projects in your modules, develop your LinkedIn and GitHub profiles in Professional Development, and learn more advanced techniques in Web Technologies.


What You Have Built

  • Lesson 4: the base styles: colours, fonts and spacing
  • Lesson 5: a skills list styled as tags
  • Lesson 6: a responsive grid of project cards
  • Lesson 7: an experience and education timeline
  • Lesson 8: navigation, contact links and a footer

Your Task

Using your web presence plan from Session 1, work through this checklist:

  1. Identity: replace Your Name in the title, header and footer, and write your own tagline.
  2. About Me: write your own two or three paragraphs, and update the LinkedIn link if you have a profile.
  3. Skills: list your own technical and transferable skills.
  4. Projects: update the cards with your own projects or "Coming Soon" placeholders.
  5. Experience: replace every entry in square brackets with your own history.
  6. Contact: use your own email address and profile links.
  7. Design: choose your own colour scheme. Change the colours consistently throughout the CSS, and keep the contrast strong.
  8. Check: test every link, and read the whole page as if you were an employer seeing it for the first time.

When you have finished, use the Download button to save your work. You will be able to put it online later in the course.


Extension Challenge: Level Up Your Portfolio

Finished already? Each level adds one improvement, and each one is a little harder than the last. Save a copy with the Download button after each level, so you always have a working version to go back to.


Level 1: Make It Interactive

Add :hover effects to your project cards and contact links. For example, change the shadow or background colour when the mouse is over them. Add transition: all 0.2s; to the normal rule (not the hover rule) so the change animates smoothly.


Level 2: Accessibility Check

Check your page against these points. Can every image be understood from its alt text alone? Does every link make sense out of context? Is there only one h1, with headings that never skip a level? Is your text contrast at least 4.5:1? Fix anything that fails.


Level 3: Add a New Section

Add a section that is not in the template, such as Certifications, Volunteering or Interests. Choose the most suitable component from this unit (a list, cards or a timeline), reuse its classes, give the section an id and add it to the navigation.


Level 4: Phone-Friendly Header

On small screens, a large header takes up most of the view. Use a media query to apply styles only below a certain screen width:

@media (max-width: 600px) {
    header {
        padding: 20px 10px;
    }
}

Reduce the header padding and h1 font size on small screens, then check the result by narrowing the preview.


Level 5: A Reflections Section

Add a Reflections section where you will post short entries about what you are learning each week. Use the card pattern with a date on each card. This will also give you material for your Professional Development portfolio, and in Session 4 you will explore whether a content management system would make this easier to maintain.


Level 6: Dark Mode (Boss Level)

Make your site switch to a dark colour scheme automatically when the visitor's device is set to dark mode, using the media query @media (prefers-color-scheme: dark). You will need to choose dark versions of every colour in your design. Hint: search for CSS custom properties (variables), which let you define each colour once at the top of your stylesheet and change it in one place. This is how most professional sites handle themes.
