Outputting Text to the Console

In Python, you use the print() function to output text to the console. This lets you display information to the user and check what your code is doing.

print("Hello, World!")

When you run this code, it will output:

Hello, World!

Text inside quotation marks is called a string. You can use single or double quotes, as long as the opening and closing quotes match.

Each print() starts on a new line:

print("Welcome to Python programming!")
print("This is my second line.")

This will output:

Welcome to Python programming!
This is my second line.

Comments

Any line that begins with # is a comment. Python ignores comments completely; they are notes for people reading your code.

# This line greets the user
print("Hello!")
