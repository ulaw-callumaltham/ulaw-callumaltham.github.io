Tutorial

A variable is a named container that stores a value so you can use it later in your program. You create a variable by giving it a name and using = to assign it a value.

name = "Sam"
age = 21
print(name)
print(age)

This will output:

Sam
21

A variable can be given a new value at any time, and the old value is replaced:

score = 10
score = 15
print(score)
15

Naming Rules

  • Names can contain letters, numbers and underscores, but cannot start with a number.
  • Names are case-sensitive: Age and age are different variables.
  • By convention, Python uses lowercase words separated by underscores, such as first_name. This is called snake_case.
  • Choose names that describe the value: total_price is far clearer than x.

Data Types

Every value in Python has a type. The four basic types are:

  • int – whole numbers, e.g. 42
  • float – numbers with a decimal point, e.g. 1.75
  • str – text (strings), e.g. "Leeds"
  • bool – either True or False

You can check the type of any value with the type() function:

print(type(42))
print(type(1.75))
print(type("Leeds"))
print(type(True))
<class 'int'>
<class 'float'>
<class 'str'>
<class 'bool'>

Note that "42" (in quotes) is a string, not a number.
