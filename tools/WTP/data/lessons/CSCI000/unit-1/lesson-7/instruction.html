Tutorial

An if statement lets your program choose what to do based on a condition.

temperature = 25

if temperature > 20:
    print("It's warm today.")
    print("Don't forget your sunglasses.")

print("Have a good day!")

Two things are essential:

  • The line with the condition ends in a colon :
  • The code that belongs to the if is indented by four spaces. Python uses indentation to know which lines are inside the if. The final print is not indented, so it always runs.

else and elif

else runs when the condition is False. elif (short for "else if") lets you check further conditions in turn.

temperature = 12

if temperature > 20:
    print("Warm")
elif temperature > 10:
    print("Mild")
else:
    print("Cold")
Mild

Python checks each condition from top to bottom and runs only the first block whose condition is True. The order of your conditions therefore matters.


Your Task

Write a program that converts a mark into a UK degree classification:

  • 70 or above: First
  • 60 to 69: Upper Second (2:1)
  • 50 to 59: Lower Second (2:2)
  • 40 to 49: Third
  • Below 40: Fail
  1. Ask the user to enter a mark and convert it to an integer.
  2. Use if, elif and else to print the correct classification.
  3. Test it with the boundary marks 70, 69, 40 and 39.

Extension Tasks

  • Before classifying, check the mark is between 0 and 100. If not, print Invalid mark instead.
  • Write a cinema ticket pricer: under 12 pays £5, 65 or over pays £6, everyone else pays £10. Then ask whether they are a student, and if so take £2 off (you will need an if inside another if or a separate check).
