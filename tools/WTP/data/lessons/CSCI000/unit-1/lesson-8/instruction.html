Tutorial

Imagine you wanted to print the numbers 1 to 100. You could write 100 print() lines, but that would be slow and error-prone, and what if you then needed 1 to 1,000? Repeating tasks is something computers are brilliant at, and in programming we do it with loops.

Python has two kinds of loop. This lesson covers the while loop, and the next covers the for loop.


The while Loop

A while loop keeps repeating a block of code as long as its condition is True. It looks very similar to an if statement, and uses the same colon and indentation rules. The difference is that an if runs its block once, whereas a while goes back and checks the condition again after every pass.

count = 1

while count <= 5:
    print(count)
    count += 1

print("Done!")
1
2
3
4
5
Done!

Tracing the Loop

Following a loop step by step (called tracing) is the best way to understand it:

  • count starts at 1. Is 1 <= 5? Yes, so print 1 and increase count to 2.
  • Is 2 <= 5? Yes, so print 2 and increase count to 3.
  • This continues for 3, 4 and 5.
  • After printing 5, count becomes 6. Is 6 <= 5? No, so the loop stops and Python moves on to print("Done!").

Almost every counting loop has the same three parts. Learn to spot them:

  1. Set up a variable before the loop (count = 1).
  2. Check a condition at the start of each pass (count <= 5).
  3. Update the variable inside the loop (count += 1), so that the condition eventually becomes False.

Avoiding Infinite Loops

If the condition never becomes False, the loop runs forever. This is called an infinite loop. In the example above, forgetting count += 1 would do exactly that: count would stay at 1, and 1 is always less than 5.

Everyone writes an infinite loop sooner or later. If your program ever freezes, refresh the page; your code is saved automatically. Then check that the variable in your condition is actually changing inside the loop.


Looping Until Something Happens

while loops really shine when you do not know in advance how many times to repeat. For example, you might keep asking for a password until the user gets it right:

password = ""

while password != "python123":
    password = input("Enter the password: ")

print("Access granted!")

Notice that password is set to an empty string before the loop. This is needed because the condition is checked before the first pass, and Python cannot compare a variable that does not exist yet. Since "" is not equal to "python123", the loop runs at least once. It may run once or fifty times, depending on the user.


Leaving a Loop Early

Sometimes you want to stop a loop part-way through. The break keyword exits the loop immediately, even if the condition is still True, and the program carries on from the first line after the loop. You will usually see break inside an if statement, e.g. "if the user types quit, break".


Common Mistakes

  • Forgetting to update the variable inside the loop, which causes an infinite loop.
  • Not setting the variable up before the loop, which causes a NameError.
  • Off-by-one errors: using < when you meant <=, so the loop runs one time too few.

Recap

  • A while loop repeats as long as its condition is True.
  • Counting loops need a set-up, a condition and an update.
  • If the condition never becomes False, you have an infinite loop.
  • break exits a loop immediately.
