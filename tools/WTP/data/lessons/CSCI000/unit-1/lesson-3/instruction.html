Tutorial

Computers were originally built to do calculations, and Python makes this easy. Whether you are adding up a shopping basket, working out an average or converting between units, you will use the arithmetic operators covered in this lesson.


The Arithmetic Operators

An operator is a symbol that tells Python to perform an action on one or more values. Most of these will look familiar from maths, although multiplication uses * rather than ×:

  • + addition
  • - subtraction
  • * multiplication
  • / division
  • // floor division
  • % modulus (remainder)
  • ** exponent (to the power of)
print(7 + 3)
print(7 / 2)
print(7 // 2)
print(7 % 2)
print(2 ** 3)
10
3.5
3
1
8

Division, Floor Division and Remainder

The first three operators behave as you would expect, but the division operators deserve a closer look.

Normal division / always gives a float, even when the answer is a whole number. 10 / 2 gives 5.0, not 5.

Floor division // and modulus % work as a pair. Imagine sharing 7 sweets between 2 people. Each person gets 7 // 2, which is 3 sweets, and there is 7 % 2, which is 1 sweet, left over. Floor division answers "how many whole times does it fit?" and modulus answers "what is left over?"

The modulus operator turns out to be surprisingly useful. For example, a number is even if dividing it by 2 leaves no remainder, so number % 2 is 0 for every even number.


Order of Operations

When a calculation has several operators, Python follows the same order as BODMAS in maths: brackets first, then powers, then multiplication and division, then addition and subtraction.

print(2 + 3 * 4)
print((2 + 3) * 4)
14
20

In the first line, Python multiplies 3 * 4 before adding 2. In the second, the brackets force the addition to happen first. If you are ever unsure, add brackets: they make your intention clear to Python and to anyone reading your code.


Calculating with Variables

Arithmetic becomes far more useful when combined with variables. Instead of typing numbers directly, you store them in variables with meaningful names and calculate with those:

price = 12.50
quantity = 3
subtotal = price * quantity
print(subtotal)
37.5

Remember that Python works out the right-hand side of = first. On the third line it looks up price (12.50) and quantity (3), multiplies them, and stores the result, 37.5, in subtotal. If the price changes later, you only need to update one line.


Updating a Variable

It is very common to change a variable based on its current value, such as adding points to a score:

score = 10
score = score + 5
print(score)
15

Read the second line as "take the current score, add 5, and store the result back in score". Because this pattern is so common, Python has a shortcut: score += 5 does exactly the same thing. There are also -=, *= and /=.


Common Mistakes

  • Using x for multiplication. Python uses *.
  • Forgetting the order of operations. 10 + 20 / 2 is 20.0, not 15.0.
  • Doing maths with numbers in quotes. "5" * 3 gives 555, because it repeats the string three times.

Extension Tasks

  • A film lasts 135 minutes. Use // and % to print how many hours and minutes that is.
  • Use % to check whether 1234567 is even or odd.
  • Use round(value, 2) to round the result of 10 / 3 to two decimal places.
  • Try print(0.1 + 0.2). The answer is not quite what you would expect, because computers store decimal numbers in binary and some cannot be represented exactly. This is why round() is useful when displaying money.

Recap

  • Python supports + - * / // % **.
  • / always gives a float; // gives the whole part and % gives the remainder.
  • Python follows BODMAS, and brackets let you control the order.
  • score += 5 is a shortcut for score = score + 5.
