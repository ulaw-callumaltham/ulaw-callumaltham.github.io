Tutorial

A list stores several values in a single variable. Lists are written with square brackets, with items separated by commas.

marks = [65, 72, 58, 81, 49]
modules = ["Python", "Databases", "Web Technologies"]

Accessing Items

Like strings, list items are numbered from index 0:

print(modules[0])
print(modules[-1])
print(len(modules))
Python
Web Technologies
3

Changing a List

modules.append("Networking")     # add to the end
modules.remove("Databases")      # remove an item
modules[0] = "Python Basics"     # replace an item
print(modules)
['Python Basics', 'Web Technologies', 'Networking']

Working Through a List

A for loop visits each item in turn:

for mark in marks:
    print(mark)

Python also has built-in functions that work on lists of numbers: sum(), min() and max(). You can check whether an item is in a list with in, e.g. "Python" in modules, and sort a list with .sort().
