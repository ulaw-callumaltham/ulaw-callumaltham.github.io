Tutorial

Before adding any more content, it helps to decide how the page is organised. Think back to the portfolio sites you looked at in Session 1. Almost all of them followed a similar pattern: a header introducing the person, a series of sections (about, skills, projects, experience, contact) and a footer. In this lesson you will build that skeleton.


Semantic Elements

HTML has a set of semantic elements. Semantic means "carrying meaning": the name of the element describes what kind of content it holds.

  • <header> the introductory content at the top of the page
  • <nav> a set of navigation links (you will add this in Lesson 8)
  • <main> the main content of the page; there should be only one
  • <section> a themed group of content, usually with its own heading
  • <footer> the closing content at the bottom of the page

None of these change how the page looks on their own. So why use them?

  • Accessibility. Screen readers use them to let visually impaired users jump straight to the main content or between sections. An accessible portfolio is also a good signal to employers.
  • Search engines use them to understand which parts of your page matter most.
  • Readability. Your code is easier to understand when the structure is named, both for you and for anyone reviewing your work.

Nesting Elements

Elements can be placed inside other elements; this is called nesting. A section contains its heading and content, and <main> contains all the sections:

<main>
    <section>
        <h2>About Me</h2>
        <p>I am an MSc Computing student...</p>
    </section>

    <section>
        <h2>Skills</h2>
    </section>
</main>

An element must be closed inside the element that contains it. Think of it like brackets in maths: the last one opened is the first one closed. Indenting nested elements is not required by the browser, but it makes the structure much easier to see and to check.


Heading Levels

Headings should form an outline of the page, like the contents page of a book. Your name is the <h1>, each section title is an <h2>, and items inside a section (such as individual projects) will be <h3>. Do not choose a heading level because of its size; size can be changed with CSS later. Choose it based on where it sits in the outline.


Your Task

  1. Wrap your <h1> and tagline in a <header> element.
  2. Create a <main> element containing five <section> elements, each with an <h2>: About Me, Skills, Projects, Experience and Education, and Contact.
  3. Move your introduction paragraph into the About Me section.
  4. Add a <footer> after </main> containing a paragraph with &copy;, the year and your name.

&copy; is an HTML entity, a code that displays a special character. It shows as ©. Entities exist for characters that are hard to type or that have a special meaning in HTML, such as &lt; for <.


Extension Tasks

  • Check your nesting: every opening tag should have a matching closing tag at the same indentation level.

Recap

  • Semantic elements describe what their content is: header, nav, main, section, footer.
  • They help screen readers, search engines and other developers.
  • Headings form an outline: h1 for your name, h2 for sections, h3 for items within them.
