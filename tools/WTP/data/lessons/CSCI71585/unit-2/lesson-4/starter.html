Binary

Binary is a base 2 number system, which means it only uses two digits: 0 and 1. To show which base a number is written in, we write the base after it, so the binary number 1010 is written as 1010 2.

Each binary digit is called a bit. 8 bits make 1 byte, which can store any number from 0 to 255.

Place Values

Each place value in a binary number is a power of 2: 2^0 = 1, 2^1 = 2, 2^2 = 4 and 2^3 = 8. So 1010 in binary is 8 + 2, which is 10 in denary. This is the most important idea in this topic.

In Python

Python can convert a denary number to binary for you. Running bin(10) returns '0b1010', where the 0b prefix shows that the number is binary.
