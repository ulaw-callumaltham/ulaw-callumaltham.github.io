Tutorial

So far, every value in our programs has been written directly into the code. That means the program does exactly the same thing every time it runs. To make programs interactive, so they respond to the person using them, we need a way to ask for information.


The input() Function

The input() function displays a message (called a prompt), then pauses the program and waits for the user to type something and press Enter. Whatever they typed is handed back to your program, so you can store it in a variable:

name = input("What is your name? ")
print(f"Hello, {name}!")
What is your name? Sam
Hello, Sam!

Step by step:

  1. Python displays What is your name? and waits.
  2. The user types Sam and presses Enter.
  3. input() gives back the text "Sam", which is stored in name.
  4. The next line uses name in an f-string.

Notice the space at the end of the prompt, just before the closing quote. Without it, the user's answer would appear squashed up against the question.


input() Always Gives You a String

This is the single most important thing to remember about input(): it always returns a string, even if the user types a number. Python has no way of knowing whether 21 is meant to be an age, a house number or part of a password, so it treats everything as text.

This causes problems as soon as you try to do maths:

birth_year = input("What year were you born? ")
age = 2026 - birth_year
TypeError: unsupported operand type(s) for -: 'int' and 'str'

Python is telling you it cannot subtract a string from a number.


Converting Between Types

The solution is to convert the string into a number. Python has a function for each type:

  • int() converts a value to a whole number
  • float() converts a value to a decimal number
  • str() converts a value to a string
current_year = 2026
birth_year = int(input("What year were you born? "))
age = current_year - birth_year
print(f"You will turn {age} this year.")

Look closely at the second line, which has one function inside another. Python works from the inside out: first input() runs and returns a string such as "2005", then int() converts that string into the number 2005, and finally the number is stored in birth_year.

Use int() for whole numbers such as ages or quantities, and float() when the user might type a decimal, such as a price or temperature.


When Conversion Fails

If the user types something that cannot be turned into a number, such as twenty, Python raises a ValueError. For now, just type sensible values when testing. Later in the module you will learn how to catch errors like this and ask the user to try again.


Common Mistakes

  • Forgetting to convert before doing maths. If adding 5 and 3 gives you 53, you have joined two strings instead of adding two numbers.
  • Using int() for decimals. int("2.5") causes a ValueError; use float() instead.
  • Missing a closing bracket when nesting functions. int(input("Age? ") needs one more ).

Extension Tasks

  • Write a temperature converter. Ask for a temperature in Celsius and print it in Fahrenheit using c * 9 / 5 + 32. Use float() so decimals work, and round() to tidy the result.
  • Write a bill splitter. Ask for the total bill and the number of people, then print how much each person pays to two decimal places.
  • What happens if you type a number with spaces around it, such as 42 ? Does int() still work?

Recap

  • input() pauses the program and returns whatever the user types.
  • The result of input() is always a string.
  • Use int() or float() to convert it before doing maths.
  • Nested functions run from the inside out.
