Tutorial

Suppose you wanted to store the marks for every student on a course. You could create mark1, mark2, mark3 and so on, but with 200 students that becomes impossible to manage. You couldn't easily loop through them, or add another student later. What you need is a single variable that holds a whole collection of values. In Python, that is a list.


Creating a List

A list is written with square brackets, with the items separated by commas. A list can hold any type of value:

marks = [65, 72, 58, 81, 49]
modules = ["Python", "Databases", "Web Technologies"]
empty = []

Lists keep their items in the order you put them in. An empty list [] is useful when you want to start with nothing and add items as your program runs.


Accessing Items

Lists use exactly the same indexing as strings, which you met in Lesson 4. The first item is at index 0, and -1 is the last item. len() tells you how many items there are:

print(modules[0])
print(modules[-1])
print(len(modules))
Python
Web Technologies
3

If you ask for an index that does not exist, such as modules[3] in a list of three items, Python raises an IndexError. Remember that a list of three items has indexes 0, 1 and 2.


Changing a List

There is one big difference between lists and strings. Strings cannot be changed once created; methods like .upper() give you a new string. Lists, however, can be changed directly, and their methods modify the list itself:

modules.append("Networking")     # add to the end
modules.remove("Databases")      # remove an item by value
modules[0] = "Python Basics"     # replace the item at index 0
print(modules)
['Python Basics', 'Web Technologies', 'Networking']

Other useful tools include .sort(), which arranges the list in order, and the in keyword, which checks whether something is in the list and gives True or False, e.g. "Python" in modules.

Because methods like .sort() change the list directly, you call them on their own line. Writing marks = marks.sort() is a common mistake: .sort() returns nothing, so you would lose your list.


Working Through a List

Lists and for loops are a natural pair. A for loop visits each item in turn, just as it visited each character of a string:

for mark in marks:
    print(mark)

A nice convention is to give the list a plural name (marks) and the loop variable the singular (mark). The code then reads as "for each mark in marks".


Built-in Functions for Lists

Python has built-in functions that work on whole lists of numbers, saving you from writing loops for common jobs:

  • sum(marks) adds up every item
  • min(marks) finds the smallest item
  • max(marks) finds the largest item

Combining these with len() gives you the average: the total divided by how many items there are.


Common Mistakes

  • Counting from 1 instead of 0, which can cause an IndexError.
  • Writing marks = marks.sort(), which replaces your list with None.
  • Using round brackets instead of square brackets to create a list.

Recap

  • A list stores a collection of values in order, inside square brackets.
  • List indexing works the same way as strings, starting at 0.
  • Lists can be changed directly with methods such as .append(), .remove() and .sort().
  • sum(), min(), max() and len() work on whole lists.
