Tutorial

Every web page you have ever visited is built on HTML. In this unit you will learn how to write it properly: how a page is structured, which elements to use for different kinds of content, and how to choose elements by what content means rather than how it looks.

This first lesson covers the foundations that everything else builds on: what HTML is, how its syntax works, and the structure every web page needs. Work through the page from top to bottom. Whenever you see a Try It section, make that change in the editor before moving on, and check the preview to see the result.


What Is HTML?

HTML stands for HyperText Markup Language.

  • HyperText is text that contains links to other text. Links are what connect individual pages into the World Wide Web.
  • Markup means labelling content to describe what it is. HTML labels one piece of text as a heading, another as a paragraph, another as a link, and so on.
  • Language means it has a defined set of rules (its syntax) that browsers understand.

HTML is a markup language, not a programming language. It has no variables, loops or logic; it simply describes the content and structure of a page. How the page looks is controlled by CSS, and how it behaves is controlled by JavaScript. You will meet both in later units.

ℹ️ Info: HTML is maintained as a "living standard" by the WHATWG (Web Hypertext Application Technology Working Group). Rather than being released in numbered versions, it is updated continuously. You will often still hear it called HTML5 which is the name for modern HTML in general.

How a Browser Uses HTML

When you visit a web page, a few things happen in order:

  1. Your browser requests the page from a web server.
  2. The server sends back an HTML file, which is just plain text.
  3. The browser reads (or parses) the HTML from top to bottom and works out what each piece of content is.
  4. The browser displays (or renders) the content on screen.

The editor and preview in this platform work the same way: the preview is a browser displaying whatever HTML you write in the editor.


Elements and Tags

HTML works by wrapping content in tags. Most tags come in pairs:

  • An opening tag: the element's name inside angle brackets, such as <p>.
  • A closing tag: the same name with a forward slash before it, such as </p>.

The opening tag, the closing tag and the content between them together form an element.

<p>This is a paragraph.</p>

Here, <p> is the opening tag, This is a paragraph. is the content, and </p> is the closing tag. The whole line is a paragraph element.

The browser does not display the tags themselves. It reads them to understand what each piece of content is, then displays the content accordingly.

💡 Tip: HTML tag names are not case-sensitive, so <P> works the same as <p>. The standard convention is to always write them in lowercase, and you should follow it.

Try It

  1. In the editor, type <p>Hello, world!</p> and check that the text appears in the preview.
  2. Now delete the closing </p> tag. Notice that the text still appears correctly.
  3. Put the closing tag back.
⚠️ Warning: Browsers are very forgiving. When HTML contains mistakes, they guess what you meant and display something anyway. This means a page can look correct while its code is broken, and different browsers may guess differently. Never rely on "it looks fine" as proof that your HTML is correct. You will learn how to check your code properly in the final lesson of this unit.

Void Elements

A small number of elements have no content to wrap, so they have no closing tag. These are called void elements. For example, <br> creates a line break and <img> displays an image. Neither has anything to put between an opening and closing tag.

<p>First line<br>Second line</p>
ℹ️ Info: You may see void elements written with a slash at the end, such as <br />. This style comes from an older, stricter version of HTML called XHTML. It is still allowed, but it is not needed, and this unit does not use it.

Elements Inside Elements

Elements can contain other elements. When one element sits inside another, the outer element is called the parent and the inner element is called the child.

<p>This is <em>very</em> important.</p>

Here, the <em> element is a child of the <p> element. An element must be closed inside its parent, so the inner element always closes first. You will look at this in much more detail in Lesson 4.


The Structure of an HTML Document

Every HTML page follows the same basic outline:

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>My First Page</title>
</head>
<body>
    <h1>Hello, web!</h1>
    <p>This is my first web page.</p>
</body>
</html>

Each part has a specific job:

  • <!DOCTYPE html>: the doctype declaration. It tells the browser the page is written in modern HTML. It is not an element and has no closing tag. It must be the very first line.
  • <html>: the root element. Every other element on the page goes inside it.
  • <head>: information about the page, such as its title and character encoding. Nothing in the head is displayed on the page itself.
  • <body>: the content of the page. Everything the user sees goes here.

The <head> and <body> are both children of <html>, and a page has exactly one of each.

⚠️ Warning: Without the doctype, browsers switch into "quirks mode", where they imitate the behaviour of very old browsers from the 1990s. Your page may still appear, but layout and styling can behave unpredictably. Always include it.
💡 Tip: Notice how elements inside <head> and <body> are indented. The browser ignores indentation, but it makes it much easier for people to see which elements sit inside which. Press Tab in the editor to indent a line.

Try It

  1. Delete everything in the editor.
  2. Type out the outline above, starting with the doctype. Type it yourself rather than copying it; writing it from scratch is the quickest way to remember it.
  3. Leave out the <meta> and <title> lines for now. Inside the <body>, add your <p>Hello, world!</p> paragraph from earlier.

The lang Attribute

The opening <html> tag contains lang="en". This is an attribute: extra information written inside an opening tag as name="value". You will learn about attributes properly in Lesson 5.

The lang attribute states the language of the page's content. It matters because:

  • Screen readers use it to choose the correct pronunciation when reading the page aloud.
  • Browsers use it to decide whether to offer a translation.
  • Search engines use it to show the page to people searching in that language.

The value is a language code, such as en for English, fr for French or cy for Welsh. You can also be more specific: en-GB means British English.

Try It

  1. If you have not already, add lang="en" to your opening <html> tag.

Inside the Head

The <head> holds information about the page, often called metadata. In this lesson you will add the two pieces every page should have.

Character Encoding

Computers store text as numbers, and a character encoding is the system that maps those numbers to characters. If the browser uses the wrong encoding, characters such as £, é or emoji can appear as scrambled symbols.

<meta charset="UTF-8">

UTF-8 can represent almost every character in every writing system, and it is the standard for the web. The <meta> element is a void element, so it has no closing tag.

💡 Tip: Make <meta charset="UTF-8"> the first line inside your <head>. The browser needs to know the encoding before it reads any text, including the title.

The Page Title

The <title> element sets the name of the page. It does not appear on the page itself. Instead, it is used:

  • In the browser tab.
  • As the default name when someone bookmarks the page.
  • As the clickable headline in search engine results.
  • By screen readers, which announce it when the page loads.

A good title is short and describes the page's content, such as Contact Us | City Library, rather than something generic like Home or Page 1.

Try It

  1. Inside your <head>, add <meta charset="UTF-8">.
  2. Below it, add a <title> element containing My First Page.
  3. The preview has no browser tab, so it shows your page's title in its header instead. Check that it has changed from No title to My First Page.

Inside the Body

Everything the user sees goes inside the <body>. You will learn about many different elements in this unit, but two of the most common are headings and paragraphs:

  • <h1> is the main heading of the page. There are six heading levels, from <h1> to <h6>, which you will cover in the next lesson.
  • <p> is a paragraph of text.

Try It

  1. Above your paragraph, add an <h1> element containing Hello, web!.
  2. Change the text of your paragraph to one sentence about why you are learning web development.

Comments

A comment is a note in your code that the browser ignores. Comments start with <!-- and end with -->, and can span several lines.

<!-- This is a comment. It will not appear on the page. -->
<h1>Hello, web!</h1>

Comments are useful for:

  • Explaining what a section of code does, for other developers or for yourself in the future.
  • Marking where sections start and end in a long page.
  • Temporarily hiding code without deleting it, which is known as "commenting out".
⚠️ Warning: Comments do not appear on the page, but they are not private. Anyone can read them by viewing the page's source code in their browser. Never put passwords, personal details or other sensitive information in an HTML comment.

Try It

  1. Above your <h1>, add a comment saying Main heading. Check that it does not appear in the preview.
  2. Wrap your paragraph in a comment to comment it out, and check that it disappears from the preview.
  3. Remove the comment markers so the paragraph appears again.

Check Your Page

Your finished code should look similar to this, with your own sentence in the paragraph:

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>My First Page</title>
</head>
<body>
    <!-- Main heading -->
    <h1>Hello, web!</h1>
    <p>I am learning web development so that I can build my own applications.</p>
</body>
</html>
