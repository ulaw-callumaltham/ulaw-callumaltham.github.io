Tutorial

Programs constantly need to answer yes-or-no questions. Is the password correct? Is the user old enough? Is the basket empty? Before we can make our programs take different actions (which you will do in the next lesson), we need a way to ask these questions and get an answer. In Python, the answer is always one of two boolean values: True or False.


Comparison Operators

A comparison checks how two values relate to each other and produces True or False:

  • == equal to
  • != not equal to
  • < less than
  • > greater than
  • <= less than or equal to
  • >= greater than or equal to
print(5 > 3)
print(10 == 9)
print("apple" == "Apple")
True
False
False

The last result surprises many people. String comparisons are case-sensitive, so a capital A is a completely different character from a lowercase a. This is exactly why passwords are case-sensitive.


= Versus ==

This is one of the most common mistakes in programming, so it is worth being clear:

  • A single = assigns: "store this value".
  • A double == compares: "are these two values the same?"

A helpful way to read == aloud is "is equal to", which reminds you that it is asking a question.


Storing the Answer

Because a comparison produces a value, you can store it in a variable just like a number or string:

age = 16
is_adult = age >= 18
print(is_adult)
False

Python works out age >= 18 first, which gives False, and then stores that value in is_adult. Giving conditions a clear name like this can make complicated code much easier to read.


Logical Operators

Real decisions often depend on more than one thing. You might go for a walk if it is the weekend and it is not raining. Python lets you combine conditions using three logical operators:

  • and is True only if both sides are True. "I need a ticket and ID to get in."
  • or is True if at least one side is True. "I can pay by cash or card."
  • not flips a value: True becomes False and vice versa.
is_weekend = True
is_raining = False
print(is_weekend and not is_raining)
print(is_weekend or is_raining)
True
True

Working through the first print: not is_raining is not False, which is True. So the expression becomes True and True, which is True.

When combining several conditions, you can add brackets to make the meaning clear, e.g. (age >= 18) and (has_ticket).


Common Mistakes

  • Using = when you mean ==.
  • Writing => or =<. The equals sign always comes second: >= and <=.
  • Forgetting case when comparing strings.

Recap

  • Comparisons produce a boolean: True or False.
  • = assigns a value; == compares two values.
  • and, or and not combine or flip conditions.
  • String comparisons are case-sensitive.
