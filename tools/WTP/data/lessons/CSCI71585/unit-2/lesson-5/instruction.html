Tutorial

Links are what turn individual pages into a web. In this lesson you will learn how to create them, and how to write the addresses they point to. First, though, you will look properly at attributes, which you have already met a few times without much explanation.

The starter code contains a page of web development resources with no links yet. As before, complete each Try It section in the editor before moving on.


Attributes

An attribute gives an element extra information or changes how it behaves. Attributes are always written inside the opening tag, as a name and a value:

<html lang="en">

Here, lang is the attribute's name, and en is its value. The rules for writing attributes are:

  • Attributes go in the opening tag, never the closing tag.
  • The name and value are joined by =, with no spaces around it.
  • The value goes in double quotes.
  • An element can have several attributes, separated by spaces. Their order does not matter.
  • Some attributes, called Boolean attributes, have no value at all. Including the attribute switches the feature on, such as reversed on an ordered list.
<ol start="3" reversed>

Some attributes only work on particular elements, such as start, which only works on <ol>. Others, called global attributes, work on any element. You have already seen lang, and in this lesson you will meet two more: title and id.


The title Attribute

The title attribute gives extra information about an element. Most browsers show it as a small tooltip when you hover over the element with a mouse.

<p>The page is written in <abbr title="HyperText Markup Language">HTML</abbr>.</p>

This example also uses <abbr>, which marks an abbreviation. Its title gives the full version.

⚠️ Warning: Do not put essential information in a title attribute. Tooltips cannot be seen on touchscreens, cannot be reached by keyboard users, and are not read out consistently by screen readers. Use it only for extra information that is helpful but not necessary.

Links

Links are created with the <a> element (short for anchor). Its href attribute (short for hypertext reference) holds the address to go to, and the content between the tags is the clickable text:

<a href="https://www.w3.org">World Wide Web Consortium</a>

An <a> element is a text-level element, so it usually sits inside a paragraph, heading or list item.

Writing Good Link Text

Link text should describe where the link goes, so that it makes sense on its own:

<!-- Avoid -->
<p>To read the HTML documentation, <a href="https://developer.mozilla.org">click here</a>.</p>

<!-- Better -->
<p>Read the <a href="https://developer.mozilla.org">MDN HTML documentation</a>.</p>
ℹ️ Info: Screen readers can list every link on a page so that users can jump straight to one. A list of links that all say "click here" or "read more" is useless, because the links only make sense alongside the text around them. Descriptive link text also tells search engines what the linked page is about.

Opening Links in a New Tab

By default, a link opens in the same tab, replacing the current page. Adding target="_blank" opens it in a new tab instead:

<a href="https://www.w3.org" target="_blank">World Wide Web Consortium</a>

On a real website, use this sparingly. Opening new tabs takes control away from the user, and can be disorientating, especially for screen reader users who may not realise a new tab has opened. Same-tab links are the normal, expected behaviour.

URLs and Paths

The value of href is a URL (Uniform Resource Locator): the address of something on the web. There are two ways to write one.

Absolute URLs

An absolute URL is the complete address, including the protocol and the domain name. It points to the same place no matter which page it is written on:

https://developer.mozilla.org/en-US/docs/Web/HTML
└─┬──┘  └─────────┬─────────┘└────────┬─────────┘
protocol       domain               path

Use absolute URLs for links to other websites. The protocol (https://) is required: without it, the browser treats the address as a file on your own site.

Relative URLs

A relative URL is a path from the current page to another file on the same website. It is shorter, and it keeps working if the whole site moves to a new domain. Relative paths work like folder paths on your own computer. Imagine a website with this structure:

my-site/
├── index.html
├── about.html
├── images/
│   └── logo.png
└── projects/
    ├── index.html
    └── weather-app.html

From my-site/index.html:

  • about.html links to a file in the same folder.
  • projects/weather-app.html goes down into the projects folder, then to the file.
  • images/logo.png works the same way for an image.

From my-site/projects/weather-app.html:

  • index.html links to projects/index.html, since that is the same folder.
  • ../about.html goes up one folder with ../, then to about.html.
  • ../images/logo.png goes up one folder, then down into images.
⚠️ Warning: On most web servers, paths are case-sensitive: Logo.png and logo.png are different files. A path that works on your own computer may break once your site is online. Name files and folders in lowercase, with hyphens instead of spaces, to avoid this.
ℹ️ Info: In this platform, each lesson has only one HTML file, so a link to another page on the same site has nothing to open. If you try one, the platform will tell you so. You will use relative paths to link between your own pages when you build a multi-page site later in the module. You will use a relative path to display an image in the next lesson.

Linking Within a Page

A link can also jump to a specific part of the same page, which is useful for long pages and contents lists. This takes two steps.

Step 1: give the element you want to jump to an id attribute. An id is a unique name for one element:

<h2 id="contact">Contact</h2>

Step 2: link to it using # followed by the id. This is called a fragment link:

<a href="#contact">Contact</a>

The rules for id values are:

  • Each id must be unique: only one element on the page can use it.
  • It cannot contain spaces. Use hyphens instead, such as id="getting-started".
  • It is case-sensitive: #Contact will not find id="contact".
💡 Tip: href="#top" is a special case: it always jumps to the top of the page, even if no element has id="top". It is ideal for "Back to top" links.

Email and Phone Links

A link can also start an email or a phone call, using a different protocol in the href:

  • mailto: opens the user's email program with a new message to that address.
  • tel: offers to call the number, which is most useful on mobile phones. Write the number without spaces.
<a href="mailto:hello@example.com">hello@example.com</a>
<a href="tel:+441130000000">0113 000 0000</a>
💡 Tip: For contact links, make the link text the address or number itself. Users who do not have an email program set up can then still read it and copy it.
