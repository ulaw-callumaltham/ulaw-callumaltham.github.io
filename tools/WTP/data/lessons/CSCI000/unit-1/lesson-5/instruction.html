Tutorial

So far our programs have used fixed values. To make them interactive, we can ask the user for information with the input() function.

name = input("What is your name? ")
print(f"Hello, {name}!")

When the program reaches input(), it pauses and shows the message. Type your answer and press Enter, and whatever you typed is stored in the variable.

What is your name? Sam
Hello, Sam!

Converting Types

input() always returns a string, even if the user types a number. To do maths with it, you must convert it:

  • int() converts to a whole number
  • float() converts to a decimal number
  • str() converts to a string
current_year = 2026
birth_year = int(input("What year were you born? "))
age = current_year - birth_year
print(f"You will turn {age} this year.")

Without int(), Python would try to subtract a string from a number and give a TypeError.

If the user types something that cannot be converted, such as twenty, Python raises a ValueError. For now, just type sensible values; you will learn how to handle bad input later in the module.
