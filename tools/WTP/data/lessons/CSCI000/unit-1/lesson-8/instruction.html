Tutorial

Loops let you repeat code without writing it out again and again. A while loop keeps repeating as long as its condition is True.

count = 1

while count <= 5:
    print(count)
    count += 1

print("Done!")
1
2
3
4
5
Done!

Each time round the loop, Python checks the condition. Once count reaches 6, the condition becomes False and the loop stops.


Avoiding Infinite Loops

If the condition never becomes False, the loop runs forever. In the example above, forgetting count += 1 would do exactly that. If your program ever freezes, refresh the page; your code is saved automatically.


Looping Until the User Gets It Right

while loops are ideal when you don't know in advance how many times to repeat:

password = ""

while password != "python123":
    password = input("Enter the password: ")

print("Access granted!")

Leaving a Loop Early

The break keyword exits a loop immediately, even if the condition is still True.
