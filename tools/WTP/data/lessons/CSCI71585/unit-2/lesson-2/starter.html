A Short History of the Web

The World Wide Web was invented by Tim Berners-Lee in 1989, while he was working at CERN, a physics research laboratory in Switzerland. Researchers there used many different computers, and sharing documents between them was difficult. Berners-Lee proposed a system of linked documents that anyone could read, from any computer. The first website went online in 1991. It explained what the web was and how to use it, and you can still visit a copy of it today.

Three inventions made the web possible, and all three are still used every time you visit a web page.

HyperText Markup Language describes the content of each page and links pages together.

A Uniform Resource Locator, or URL, gives every page on the web its own unique address.

The HyperText Transfer Protocol is the set of rules browsers and servers use to request and send pages.
