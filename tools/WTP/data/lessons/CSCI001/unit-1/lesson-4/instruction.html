What Is CSS?

CSS (Cascading Style Sheets) controls how HTML content looks: colours, fonts, spacing and layout. Keeping content (HTML) and presentation (CSS) separate is a key principle of web development. It means you could completely change the look of your site without touching a single word of its content. Switch to the CSS tab in the editor to write your styles.


How a CSS Rule Works

CSS is written as a set of rules. Each rule says which elements to style, and how:

h2 {
    color: #94248C;
    border-bottom: 2px solid #94248C;
}
  • The selector (h2) chooses which elements the rule applies to; here, every h2 on the page.
  • The curly brackets contain one or more declarations.
  • Each declaration has a property (what to change) and a value (what to change it to), separated by a colon and ended with a semicolon.

A missing semicolon or bracket is the most common CSS mistake. Unlike Python, CSS does not show an error; the broken rule is simply ignored, so if a style does not appear, check your punctuation first.


Selectors

There are three kinds of selector you will use most:

  • An element selector such as section styles every element of that type.
  • A class selector starts with a full stop, such as .profile-photo, and styles every element with class="profile-photo". Classes let you style specific elements without affecting all elements of the same type.
  • A descendant selector such as header h1 styles only the h1 elements that are inside a header.

Colour, Fonts and Spacing

Colours can be written as names (white) or hex codes (#44294A). Pick two or three colours and use them consistently. Most importantly, make sure there is strong contrast between text and background so your page is easy to read for everyone.

Spacing is controlled with two properties, best understood as part of the box model: every element is a rectangular box.

  • padding is the space inside the box, between its content and its edge.
  • margin is the space outside the box, pushing other elements away.

Setting a max-width on the body with margin: 0 auto keeps your text in a comfortable column in the middle of wide screens, instead of stretching right across them.


Your Task

The CSS tab contains empty rules, with suggested values in the comments above each one.

  1. Fill in the body rule to set the font, line height, text and background colours, and the centred column.
  2. Style the header with a background colour, white text, padding and centred text.
  3. Space out the sections and style the h2 headings.
  4. Change at least one colour to make the design your own. Keep the contrast strong.

A rule for .profile-photo is already included so you can see a class selector in action: border-radius: 50% turns the square photo into a circle.


Extension Tasks

  • Try a different font, such as Georgia, serif or Verdana, sans-serif. The fonts after the first are fallbacks in case it is not available.
  • Search for an online contrast checker and test your text and background colours. Aim for a ratio of at least 4.5:1.

Recap

  • CSS controls appearance; HTML controls content and structure.
  • A rule is a selector followed by declarations of property: value;
  • Class selectors start with a full stop and target elements by their class attribute.
  • padding is space inside an element; margin is space outside it.
