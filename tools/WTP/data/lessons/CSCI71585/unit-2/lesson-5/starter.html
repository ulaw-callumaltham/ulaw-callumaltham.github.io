Web Development Resources

A collection of useful resources for learning web development, from MDN's documentation to the official standards.

Contents

Documentation

The MDN HTML documentation explains every HTML element and attribute, with examples. It is the best place to check how something works.

Standards

The World Wide Web Consortium develops standards for the web, including guidelines for making websites accessible.

Practice

The best way to learn is to build things. Try recreating the structure of a page you use every day, such as a news article or a recipe.
