Tutorial

Lists are one of the most common structures on the web. Shopping baskets, search results, navigation menus, step-by-step instructions and bullet-pointed summaries are all lists. In this lesson you will learn the two main types of list in HTML, and when to use each one.

The starter code contains a recipe page. The ingredients and method have been written as plain text that only looks like lists. Over this lesson you will convert them into real HTML lists. Complete each Try It section in the editor before moving on.


Why Use List Elements?

You could fake a list by typing a dash or a number at the start of each line and separating the lines with <br>. The page would look similar, but the browser would only see one paragraph of text. Using real list elements tells the browser that the content is a list, which has several benefits:

  • Accessibility: screen readers announce a list and how many items it contains (for example, "list, 6 items"), so users know what to expect and can skip past it.
  • Automatic numbering: numbered lists count themselves, so adding or removing a step never means renumbering by hand.
  • Styling: real lists can be restyled with CSS, for example turning a list of links into a horizontal navigation menu.

Unordered Lists

An unordered list is for items where the order does not matter. It is created with the <ul> element, and each item in the list is wrapped in an <li> (list item) element.

<ul>
    <li>Laptop</li>
    <li>Charger</li>
    <li>Notebook</li>
</ul>

By default, browsers display each item with a bullet point. Rearranging these items would not change their meaning, which is the test for whether a list is unordered.

⚠️ Warning: The only element allowed directly inside a <ul> is <li>. If you want a heading, paragraph or anything else in a list, it must go inside an <li>, or outside the list entirely.

  1. Under the Ingredients heading, the ingredients are written as a paragraph, with a dash at the start of each line and <br> elements between them. Replace the whole paragraph with a <ul>.
  2. Put each ingredient in its own <li>, and remove the dashes and <br> elements, since the list now handles both.

Ordered Lists

An ordered list is for items where the order matters, such as steps in a process, rankings or directions. It is created with the <ol> element, and its items also use <li>.

<ol>
    <li>Open the editor.</li>
    <li>Write your HTML.</li>
    <li>Check the preview.</li>
</ol>

Browsers number the items automatically, starting from 1. If you add, remove or move an item, the numbers update themselves.

💡 Tip: To decide between the two, ask: "If I shuffled these items, would the meaning change?" If yes, use <ol>. If no, use <ul>. A recipe's method must be followed in order, but its ingredients can be listed in any order.

Try It

  1. Under the Method heading, the steps are written as a paragraph with hand-typed numbers. Replace the paragraph with an <ol>, putting each step in its own <li>. Remove the typed numbers, since the list now provides them.
  2. Add a new step between steps 2 and 3: Add the garlic and cook for 1 more minute. Notice that every step after it renumbers automatically.

Changing the Numbering

Ordered lists can take attributes (which you will learn about properly in Lesson 5) to change how they count:

  • start sets the first number: <ol start="5"> counts from 5. This is useful when a list continues after some other content.
  • reversed counts down instead of up: <ol reversed>. This is useful for countdowns, such as a "top 10" list.
  • type changes the style of numbering: <ol type="a"> uses lowercase letters, "A" uppercase letters, "i" lowercase Roman numerals and "I" uppercase Roman numerals.
<h2>Top 3 Programming Languages to Learn</h2>
<ol reversed>
    <li>JavaScript</li>
    <li>SQL</li>
    <li>Python</li>
</ol>

This list displays as 3, 2, 1.

ℹ️ Info: reversed is a Boolean attribute: it has no value, and simply including it switches the feature on. You will see more of these later, such as controls on videos and required on form fields.

Writing List Items

A few habits make lists easier to read:

  • Keep items parallel. Start each item the same way. In the method, every step starts with a verb: Heat, Add, Pour.
  • Keep items short. If an item needs several sentences, it may be better as a paragraph.
  • Introduce the list. A heading or short sentence before a list tells the reader what it contains.

Check Your Page

Check that:

  • The ingredients are an <ul>, with each ingredient in its own <li>.
  • The method is an <ol> with seven steps, numbered automatically by the browser.
  • No dashes, hand-typed numbers or <br> elements are left in either list.
  • The tips section has its own heading and list.

Your ingredients list should be structured like this:

<h2>Ingredients</h2>
<ul>
    <li>1 tablespoon olive oil</li>
    <li>1 onion, chopped</li>
    <!-- ...and so on for the other ingredients -->
</ul>
