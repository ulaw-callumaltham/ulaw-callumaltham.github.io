Tutorial

Every element you have used so far tells the browser what a piece of content is: a heading, a list, an image, a table. Sometimes, though, you need to group content together without saying anything about its meaning, usually so that you can style or control the group later with CSS or JavaScript. In this lesson you will learn the two elements that do exactly this, and the class attribute that gives each group a name.

You will also learn the difference between block and inline elements, which explains much of how the browser has been laying out your pages.

The starter code contains an events page for a student society. As before, complete each Try It section in the editor before moving on.


Block and Inline Elements

Look back at the pages you have built so far, and you will notice that elements are laid out in two different ways.

Block elements:

  • Always start on a new line.
  • Stretch across the full width available to them.
  • Stack vertically, one below another.
  • Examples: <h1> to <h6>, <p>, <ul>, <ol>, <li>, <table>, <figure> and <pre>.

Inline elements:

  • Sit within a line of text, without starting a new line.
  • Are only as wide as their content.
  • Flow along the line, one after another, like words in a sentence.
  • Examples: <a>, <strong>, <em>, <code>, <sup>, <abbr> and <img>.

This explains the nesting rule from Lesson 4: a block element like a list cannot go inside a paragraph, because a paragraph is a block that can only contain text and inline elements. Inline elements, on the other hand, are designed to go inside blocks.

ℹ️ Info: "Block" and "inline" describe how an element is displayed by default, and CSS can change this. For example, CSS is often used to display list items in a row to build a navigation bar. What CSS cannot change are HTML's nesting rules, which stay the same however an element is displayed.

Grouping with div and span

HTML has two generic elements, which have no meaning of their own:

  • <div> (short for division) is a generic block element. It groups larger sections of content, such as several paragraphs, a heading and its text, or a whole area of a page.
  • <span> is a generic inline element. It marks part of a line of text, such as a word or a date.
<div>
    <h3>Coding Club</h3>
    <p>Every <span>Tuesday at 5pm</span> in the library.</p>
</div>

On their own, <div> and <span> change nothing about how the page looks, and nothing about how screen readers or search engines understand it. Their only purpose is to create a group that CSS and JavaScript can then target. That makes them almost useless until you give them a name, which you will do with the class attribute shortly.

Try It

  1. At the bottom of the starter page is a Practice Area containing two short phrases, each in a <span>. Notice that they sit side by side on the same line, because <span> is inline.
  2. Change both <span> elements to <div> elements, remembering their closing tags. Notice that each one now starts on its own line, because <div> is a block.
  3. Change them back to <span> elements.

The class Attribute

The class attribute gives an element a name that CSS and JavaScript can use to find it. Unlike an id, a class is designed to be reused: many elements can share the same class, so they can all be styled the same way.

<div class="event">
    <h3>Coding Club</h3>
    <p>Every <span class="date">Tuesday at 5pm</span> in the library.</p>
</div>

<div class="event">
    <h3>Games Night</h3>
    <p><span class="date">Friday at 7pm</span> in the student union.</p>
</div>

In the next unit, a single CSS rule for the event class could give every event a border and a background colour, and a rule for the date class could make every date bold and coloured.

An element can have several classes, separated by spaces:

<div class="event featured">

This element belongs to both the event class and the featured class, so it would get the styles for an event, plus any extra styles for featured content.

Choosing Class Names

  • Describe what the content is, not how it looks. class="warning" is better than class="red-text": if the design later changes to orange warnings, the name red-text would be wrong.
  • Use lowercase, with hyphens between words, such as class="event-date". Class names are case-sensitive and cannot contain spaces, since a space separates two different classes.

id or class?

  • Use an id for something unique on the page, especially as a target for a fragment link. Each id can only be used once.
  • Use a class for anything you might want to style or select as a group. A class can be used as many times as you like.
💡 Tip: When in doubt, use a class. Even if only one element uses it today, a class leaves you free to reuse it later, while a duplicated id is an error.

Try It

  1. On the starter page, each event is made up of an <h3> and a paragraph. Wrap each event's heading and paragraph together in a <div> with a class of event.
  2. In each event's paragraph, wrap the day and time in a <span> with a class of date.
  3. The Hackathon is the society's biggest event of the year. Give its <div> a second class of featured.
  4. Each event's price is at the end of its paragraph. Wrap each price in a <span> with a class of price. For the events that are free, add a second class of free.
  5. Check the preview. Nothing should have changed, because these elements and classes only add structure for CSS to use later.

When to Use div and span

<div> and <span> are useful, but they should be your last choice, not your first. Before reaching for one, check whether there is an element that describes the content's meaning: a heading, a paragraph, a list, a figure, or <strong> for important text.

⚠️ Warning: A page built almost entirely from <div> elements, sometimes called "div soup", looks fine in the browser but tells screen readers and search engines almost nothing about its content. In the next lesson, you will learn the elements HTML provides for structuring whole pages meaningfully, and you will rebuild a div-based page using them.

Check Your Page

Each of your events should be structured like this:

<div class="event">
    <h3>Coding Club</h3>
    <p>Every <span class="date">Tuesday at 5pm</span> in the library. <span class="price free">Free</span></p>
</div>

Also check that:

  • All four events are wrapped in a <div class="event">, and the Hackathon also has the featured class.
  • Every date and every price is in a <span> with the correct class.
  • Only the free events have the free class.
  • The preview looks exactly the same as it did before you started.
