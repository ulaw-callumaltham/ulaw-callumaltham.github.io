Tutorial

Your portfolio now has all its main content. The last two pieces are about helping visitors use it: a navigation menu so they can jump to the section they care about, and a contact section so they know how to reach you. After all, the point of a portfolio is to start a conversation.


Linking Within a Page

In Lesson 3 you linked to other websites. Links can also jump to a specific place on the same page. This takes two steps.

First, give the target element an id. An id is a unique name; unlike a class, each id can only be used once on a page:

<section id="projects">

Then link to it using # followed by the id. The # tells the browser to look on the current page rather than go to a new one:

<a href="#projects">Projects</a>

Clicking the link scrolls straight to that section. On a long single-page portfolio, this saves visitors from scrolling past content they are not interested in.


The Navigation Menu

A group of navigation links belongs inside a <nav> element, which screen readers announce as navigation. It usually goes in the header so it is the first thing visitors see:

<nav>
    <a href="#about">About</a>
    <a href="#skills">Skills</a>
    <a href="#projects">Projects</a>
</nav>

The CSS uses flexbox again, the same technique as the skills list, to line the links up in a row. Removing the underline with text-decoration: none gives a cleaner look, and the nav a:hover rule brings it back when the mouse is over a link, so visitors can still tell they are links.


Contact Links

Make it as easy as possible for someone to get in touch. A special kind of link, mailto:, opens the visitor's email program with your address already filled in:

<a href="mailto:alex.morgan@example.com">Email</a>

Use a professional email address, and consider a separate one for job hunting. Alongside it, link to your LinkedIn and GitHub profiles, which you will develop in your Professional Development module. Your portfolio, LinkedIn and GitHub should feel like three parts of one consistent presence.

Note that any email address published on a website can be collected by spam bots. Many developers accept this for a job-hunting address; others leave the email out and rely on LinkedIn for contact. It is your choice.


Your Task

  1. Give each section an id: about, skills, projects, experience and contact.
  2. Add a <nav> inside the header with a link to each section.
  3. In the Contact section, add a list with class="contact-links" containing links for Email (using mailto:), LinkedIn and GitHub.
  4. Complete the nav, contact and footer rules in the CSS tab.
  5. Test every link in the preview.

Extension Tasks

  • Add scroll-behavior: smooth; to a new html rule in your CSS so the page glides to each section instead of jumping.
  • Add a Back to top link in the footer using href="#".

Recap

  • An id is a unique name for one element; href="#id" links to it.
  • Group navigation links in a nav element.
  • mailto: links open an email with your address filled in.
  • Your portfolio, LinkedIn and GitHub should present one consistent identity.
