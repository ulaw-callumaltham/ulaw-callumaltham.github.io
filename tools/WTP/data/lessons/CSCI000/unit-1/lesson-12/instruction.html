Tutorial

In this final lesson you will combine everything from this unit to build a complete game. The computer picks a secret number between 1 and 100, and the player keeps guessing until they find it, getting a hint after each guess.


Importing a Module

Python comes with many ready-made modules of extra functions. To use one, you import it at the top of your file. The random module can pick random numbers:

import random

secret = random.randint(1, 100)   # a whole number from 1 to 100
print(secret)

Run this a few times and you will get a different number each time.


Planning the Game

Before writing code, it helps to plan the steps:

  1. Pick a random secret number.
  2. Set the number of attempts to 0.
  3. Repeat until the guess is correct:
    • Ask the player for a guess and convert it to an integer.
    • Add 1 to the attempts.
    • If the guess is too high or too low, tell the player.
  4. Congratulate the player and tell them how many attempts they took.

Each step uses something you have already learnt: variables, input, comparisons, if statements, a while loop and a function.


Your Task

Complete the play_game() function in the starter code so the game works as planned above. A sample game might look like this:

I'm thinking of a number between 1 and 100.
Your guess: 50
Too high!
Your guess: 25
Too low!
Your guess: 37
Correct! You got it in 3 attempts.

Tip: while testing, temporarily print the secret number so you can check your logic.


Extension Tasks

  • Limit the player to 7 attempts. If they run out, reveal the number and end the game.
  • When the game ends, ask Play again? (y/n) and start a new game if they answer y.
  • Add difficulty levels: easy (1 to 10), medium (1 to 50) and hard (1 to 100). Pass the maximum number into play_game() as a parameter.
  • Keep track of the player's best score across several games using a list.
