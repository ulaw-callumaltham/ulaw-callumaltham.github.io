Tutorial

Welcome to Python! Python is a high-level, interpreted programming language used in web development, data science, automation and artificial intelligence. "High-level" means it is written in a way that is close to plain English, so you can focus on solving problems rather than on how the computer works internally. "Interpreted" means Python reads and runs your code one line at a time, which makes it quick to experiment with.

In this unit you will work through twelve short lessons. Each one introduces a single idea, explains how it works, gives you a task to complete in the editor, and finishes with extension tasks if you want an extra challenge.


In this unit, we will cover:

  • Working with strings and user input
  • Making decisions with if statements
  • Repeating code with while and for loops
  • Storing collections of data in lists
  • Writing your own functions
  • Bringing it all together in a small game

What Is a Program?

A program is simply a list of instructions for the computer to follow. Python starts at the first line of your file and works downwards, carrying out each instruction in order. It does exactly what you tell it, no more and no less, so the order you write things in matters.

When your program wants to show you something, it writes it to the console. On this platform, the console is the output area below the editor.

Outputting Text to the Console

The first instruction most programmers learn is how to display a message. In Python, you do this with the print() function.

A function is a named command that performs a job for you. You use (or "call") a function by writing its name followed by round brackets. Anything you put inside the brackets is the information you are giving the function to work with. Here, we give print() the message we want it to display:

print("Hello, World!")

When you run this code, it will output:

Hello, World!

Notice that the quotation marks do not appear in the output. They are there to tell Python where the text starts and ends.


Strings

A piece of text inside quotation marks is called a string (think of it as a string of characters joined together). You can use single quotes 'like this' or double quotes "like this", as long as the opening and closing quotes match.

The quotes really matter. Without them, Python assumes the word is the name of something it should already know about. If it cannot find anything with that name, it stops and shows an error:

print(Hello)
NameError: name 'Hello' is not defined

Don't worry when you see an error. Errors are Python's way of telling you exactly what went wrong and on which line. Reading them carefully is one of the most useful skills you will develop.


Several Lines of Output

Each print() displays its message on a new line. Because Python works from top to bottom, the lines appear in the order you wrote them:

print("Welcome to Python programming!")
print("This is my second line.")

This will output:

Welcome to Python programming!
This is my second line.

Comments

As your programs grow, it helps to leave notes explaining what your code does and why. Any line that begins with # is a comment. Python ignores comments completely; they exist only for people reading the code, including you in a few weeks' time.

# This line greets the user
print("Hello!")

Good comments explain the purpose of the code rather than repeating it word for word. You will see comments marked TODO in the starter code throughout this unit; these show you where to write your answers.


Common Mistakes

  • Missing quotes around text, which causes a NameError.
  • Mismatched quotes, such as "Hello', which causes a SyntaxError.
  • A missing bracket at the end of the line, which also causes a SyntaxError.
  • A capital letter: Print() is not the same as print(). Python is case-sensitive.

Extension Tasks

  • print() can take several values separated by commas. Try print("Python", "is", "fun"). What does Python put between the values?
  • You can change what goes between the values with sep: print("01", "10", "2026", sep="/"). Use it to print a date in your own format.
  • Inside a string, \n starts a new line. Print a three-line poem using a single print().

Recap

  • A program is a list of instructions that Python runs from top to bottom.
  • print() displays information in the console.
  • Text must go inside matching quotation marks; this is called a string.
  • Lines starting with # are comments and are ignored by Python.
