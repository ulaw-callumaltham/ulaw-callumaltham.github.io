Tutorial

Python can be used as a powerful calculator. These are the arithmetic operators you will use most often:

  • + addition
  • - subtraction
  • * multiplication
  • / division (always gives a float)
  • // floor division (divides and rounds down to a whole number)
  • % modulus (the remainder after division)
  • ** exponent (to the power of)
print(7 + 3)
print(7 / 2)
print(7 // 2)
print(7 % 2)
print(2 ** 3)
10
3.5
3
1
8

Order of Operations

Python follows the same order as BODMAS in maths: brackets first, then powers, then multiplication and division, then addition and subtraction.

print(2 + 3 * 4)
print((2 + 3) * 4)
14
20

Calculating with Variables

Arithmetic works with variables too, and you can store the result in a new variable:

price = 12.50
quantity = 3
subtotal = price * quantity
print(subtotal)
37.5

A common shortcut is to update a variable using its own value. count += 1 is the same as count = count + 1. There are also -=, *= and /=.
