Tutorial

From this lesson onwards, you will build components: reusable building blocks that present a particular kind of information. Most portfolio sites are made from a small number of components like these, arranged in different ways. The first is a skills list.


Lists in HTML

HTML has two main kinds of list:

  • <ul> an unordered list, for items where the order does not matter (shown with bullet points by default)
  • <ol> an ordered list, for steps or rankings (shown with numbers)

Each item in either kind of list goes inside an <li> (list item) element:

<ul class="skills">
    <li>Python</li>
    <li>SQL</li>
    <li>Stakeholder communication</li>
</ul>

A skills list is a list of separate items in no particular order, so <ul> is the right choice. Using a real list, rather than a paragraph of words separated by commas, also means a screen reader will announce "list, 6 items", which helps users understand the content.


Choosing Your Skills

Include a mix of:

  • Technical skills you are learning on the course, such as HTML, CSS, Python and SQL. It is fine to include skills you are still developing; your projects will show the level.
  • Transferable skills from your previous degree, work or other experience, such as research, data analysis, project management, customer service or report writing. These are often what set conversion students apart.

Be honest. An interviewer may well ask you about anything listed on your portfolio.


Turning a List into Tags

A bulleted list works, but many portfolios show skills as rounded "tags". This uses a technique called flexbox, which arranges the children of an element in a row.

.skills {
    list-style: none;
    padding: 0;
    display: flex;
    flex-wrap: wrap;
    gap: 10px;
}
  • list-style: none and padding: 0 remove the bullet points and the default indent.
  • display: flex lines the list items up in a row.
  • flex-wrap: wrap lets the items move onto a new line when they run out of space, so the list works on narrow screens.
  • gap adds space between the items.

Then style each item with .skills li, giving it a background colour, padding and a large border-radius to round the corners into a pill shape.

Notice that the HTML has not changed at all to achieve this. It is still a plain list, and the CSS alone changes how it looks. This is the separation of content and presentation from the last lesson in action.


Your Task

  1. In the Skills section, add a <ul> with class="skills".
  2. Add at least six skills: a mix of technical and transferable.
  3. Complete the .skills and .skills li rules in the CSS tab.

Extension Tasks

  • Split your skills into two lists with <h3> headings: Technical Skills and Transferable Skills.
  • Add a second class to your technical skills, e.g. <li class="tech-skill">, and give them a different colour. An element can have several classes separated by spaces.

Recap

  • Use ul for unordered items and ol for ordered steps; each item is an li.
  • Flexbox (display: flex) arranges elements in a row; flex-wrap lets them wrap.
  • The same HTML can look completely different depending on the CSS.
